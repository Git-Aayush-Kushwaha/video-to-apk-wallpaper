# 🎥 Video Live Wallpaper Template (Android)

This is an Android Studio template that allows you to set a **video as a live wallpaper**.
The video plays after unlocking the device and remains static on the lock screen.

---

## 🚀 Features
- Video as Live Wallpaper
- Static preview on Lock Screen
- Auto start after unlock
- Easy to replace video
- Android Studio ready project

---
